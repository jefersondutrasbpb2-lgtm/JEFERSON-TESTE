Como funciona

  1. O áudio é lido aqui no seu navegador. Nada é enviado para servidor.
  2. O espectro é convertido em 12 notas (cromagrama) a cada 0,19 s.
  3. Cada trecho é comparado com os 24 acordes maiores e menores, com peso para o baixo e para o tom estimado.
  4. Revise e corrija os acordes ouvindo junto. Depois envie para a cifra e escreva a letra.

Servidor de análise (opcional)

Com o servidor da pasta api/ rodando, dá para colar link do YouTube, separar os instrumentos e transcrever a letra já com os acordes em cima.

Sem servidor, links do YouTube não funcionam: o navegador não consegue baixar o áudio. Use um arquivo do aparelho.

Resultado

Quando você escolher um arquivo, o player aparece aqui com o acorde atual em destaque.
